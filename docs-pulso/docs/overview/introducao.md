O Pulso Emocional é uma aplicação web focada em fornecer insights rápidos e precisos sobre a opinião pública em vídeos do YouTube. Construído sob o modelo de MicroSaaS (Software as a Service), ele oferece uma funcionalidade única e essencial para criadores de conteúdo, analistas de marketing e pesquisadores.

# Missão do Projeto

O objetivo principal do Pulso Emocional é transformar o volume bruto e desestruturado de comentários do YouTube em insights de sentimento claros e acionáveis.

A aplicação automatiza todo o processo: desde a coleta de dados até a classificação avançada via Inteligência Artificial, permitindo que o usuário visualize rapidamente o "pulso emocional" de sua audiência.

# Principais Funcionalidades

Análise Automatizada: Coleta, processamento e classificação de sentimentos em tempo real.

Inteligência Artificial (Gemini): Motor de classificação que categoriza os comentários como Positivos, Negativos ou Neutros, tipos de emoções geradas sumarização dos comentários.


Validação de Qualidade(foi aplicada para fins didáticos): Cálculo do Coeficiente Kappa para medir a confiabilidade da classificação do modelo.

Dashboard Interativo: Visualização clara da distribuição de sentimentos e métricas chave.

# Tecnologias-Chave

O sistema combina as seguintes tecnologias modernas:

Backend: Python com o framework FastAPI.

Análise: API do Google Gemini.

Frontend: Interface construída em React.js.
